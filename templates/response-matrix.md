# 点对点应答表（模板）

> 使用说明：
> 1. **招标要求（原文）列必须逐字照抄**招标文件，不得改写、概括、合并；
> 2. **响应情况**只允许三值：`完全响应` / `部分响应` / `不响应`；
> 3. **偏离**只允许三值：`无偏离` / `正偏离` / `负偏离`；
> 4. **对应章节**必须填具体章节号，"见技术方案"视为未填；
> 5. 表头中的项目信息务必与封面一致。
