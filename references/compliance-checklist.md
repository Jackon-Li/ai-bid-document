# 交付前合规核对清单（Compliance Checklist）

用途：投标文件装订之前的**最后一道闸门**。
建议打印出来逐项打勾——**不勾完不签字，不签字不送印**。

标注 ⚠️ 的项是**高频废标点**，一旦出问题往往无法补救。

---

## A. 资格与准入（不满足即出局）

- [ ] A1 营业执照在有效期内，经营范围覆盖本项目内容
- [ ] A2 全部资格条件逐条自查，且有对应证明材料
- [ ] A3 ⚠️ 资质证书在有效期内（重点查年检、换证、有效期截止日）
- [ ] A4 财务报告/审计报告年度符合要求
- [ ] A5 社保、纳税证明的**所属期间**符合要求（常见错：提交的是上上月的）
- [ ] A6 无重大违法记录声明已按格式出具
- [ ] A7 联合体投标的，联合体协议已签署且分工明确（若不接受联合体，确认我方非联合体）
- [ ] A8 不存在被列入失信名单、政府采购严重违法失信名单的情形（自查并留存截图）

---

## B. 符合性审查（废标高发区）

- [ ] B1 ⚠️ 投标文件份数：正本 \_\_ 份、副本 \_\_ 份、电子版 \_\_ 份（逐个核对，少一份即废）
- [ ] B2 ⚠️ 装订方式符合要求（胶装/骑马钉/活页——**活页常被禁止**）
- [ ] B3 ⚠️ 密封与标记：封套标识、骑缝章、封口处盖章是否齐全
- [ ] B4 ⚠️ 投标函已按格式填写并加盖公章、法定代表人签字（或授权代表签字 + 授权书）
- [ ] B5 ⚠️ 法定代表人授权委托书已附，且被授权人签字与身份证一致
- [ ] B6 ⚠️ 报价表已填写，大小写金额一致，无涂改（涂改处是否需盖章确认，查招标要求）
- [ ] B7 投标有效期承诺 ≥ 招标要求天数
- [ ] B8 投标保证金已缴纳，形式（转账/保函）与金额符合要求，凭证已附
- [ ] B9 目录页码与实际页码一致
- [ ] B10 全文无他人名称、他项目名称残留（**模板复用的头号事故**）
- [ ] B11 要求的格式文件（投标函、报价表、承诺函）使用招标方提供的**原格式**，未自行改动版式

---

## C. 技术响应完整性

- [ ] C1 ⚠️ `requirements.csv` 中 mandatory=Y 的条目**覆盖率 = 100%**（跑 validate_bid.py 确认）
- [ ] C2 点对点应答表已逐条填写，无空行、无"见方案"式敷衍
- [ ] C3 ⚠️ 应答表中无"部分响应""基本满足"等灰色表述（会被判不响应）
- [ ] C4 技术偏离表已填，无偏离的项已明确写"无偏离"
- [ ] C5 招标指定的品牌/型号/标准已响应，或已提出偏离并说明理由
- [ ] C6 技术参数无低于招标门槛值的情况（逐项比对，特别注意"≥/≤"方向）
- [ ] C7 ⚠️ 所有 `[待确认]` 标记已清零（脚本检查 + 人工全文搜索双确认）
- [ ] C8 引用的标准号、协议号准确（GB/T 28181、GB 50348 等，错号等于没引用）

---

## D. 商务条款

- [ ] D1 工期/交货期承诺 ≤ 招标要求
- [ ] D2 付款方式接受招标条件（或已明确偏离并说明）
- [ ] D3 质保期 ≥ 招标要求
- [ ] D4 履约保证金接受比例与形式
- [ ] D5 违约责任条款已由商务/法务确认接受
- [ ] D6 知识产权归属条款已确认（定制开发类项目重点）
- [ ] D7 保密条款已确认
- [ ] D8 ⚠️ 报价未超最高限价，未低于成本价（低于成本需提供说明）

---

## E. 服务与实施承诺

- [ ] E1 售后响应时限、到场时限已由服务部门核定（**不是投标组自己写的**）
- [ ] E2 服务网点覆盖项目所在地（承诺的到场时间与网点距离是否匹配）
- [ ] E3 备件供应方案与库存承诺已核实
- [ ] E4 培训方案的人天、人数、场地责任划分清晰
- [ ] E5 项目经理与关键人员已确认可投入，无一人多项目冲突
- [ ] E6 实施进度计划与招标工期匹配，关键里程碑清晰
- [ ] E7 验收标准与招标验收条款一致

---

## F. 一致性交叉检查（最容易被忽略）

- [ ] F1 技术方案中的工期 = 商务标中的工期 = 进度计划中的工期（三处必须一致）
- [ ] F2 技术方案中的人员 = 人员配置表中的名单
- [ ] F3 应答表中的参数 = 技术方案正文中的参数
- [ ] F4 报价表中的设备清单 = 技术方案中的设备清单（型号、数量逐项对齐）
- [ ] F5 公司名称、项目名称、招标编号全文一致
- [ ] F6 正本与副本内容完全一致
- [ ] F7 电子版与纸质版内容一致（**常见事故：改了纸质版忘了更新 U 盘**）
- [ ] F8 页眉页脚中的项目名称与封面一致

---

## G. 最后一小时清单（送印前）

- [ ] G1 全文搜索框依次搜：`待确认`、`TODO`、`XXX`、`补`、`？？`、`示例`、`模板`
- [ ] G2 全文搜索上一版项目名称，确认无残留
- [ ] G3 目录已重新生成（Word：右键目录 → 更新域 → 更新整个目录）
- [ ] G4 页码连续，无断页、无空白页
- [ ] G5 图表编号连续，图注与正文引用一致
- [ ] G6 打印一份黑白稿检查（彩色图转黑白后是否还能看清）
- [ ] G7 装订后翻一遍，确认无倒页、缺页、夹页
- [ ] G8 密封前拍照留存（封套外观 + 骑缝章）
- [ ] G9 确认递交时间与地点，预留交通与排队时间
- [ ] G10 递交回执/签收单已取回并归档

---

## 使用方式

1. 打印本清单，A–F 部分由**技术、商务、资质三个口分别自查**，交叉签字；
2. G 部分由**一个人独立完成**（不要让写方案的人自查最后一步，会产生盲区）；
3. 任何一项打不了勾 → 记录问题与责任人 → 修复后重新过该项；
4. 清单归档，作为项目过程文件留存（后续质疑投诉时是重要证据）。
