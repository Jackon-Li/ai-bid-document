# 评分办法拆解与得分策略（Scoring Matrix）

投标不是"把方案写好"，是**在评分表上把分拿满**。
本文件的作用：把评分办法变成一张可执行的作战表。

---

## 一、先算清三个数字

拿到评分办法后，第一件事不是写方案，是算账：

```
1. 理论满分 = Σ 各评分项满分（通常 100 分）
2. 我方可达分 = Σ (各评分项 我方预期得分)
3. 分差 = 理论满分 - 我方可达分
```

**分差就是全部工作重点。** 分差集中在哪几项，资源就往哪投。

同时确认三条及格线（任一不满足则前面全白做）：

- **资格线**：是否满足全部资格条件
- **符合性线**：是否通过符合性审查（格式、签章、密封、有效期）
- **价格线**：报价是否在预算/最高限价内，是否低于成本价

> 实践中，**80% 的失败不是输在方案分，而是输在资格与符合性**。先保命，再争分。

## 二、评分项分类与应对策略

| 类型 | 特征 | 策略 | 常见分值 |
|---|---|---|---|
| **价格分** | 公式化计算，通常低价高分 | 由商务决策，本技能不介入测算 | 30–50 |
| **技术方案分** | 主观评分，评委打分 | 结构化 + 逐条对应 + 图表化 | 20–40 |
| **业绩案例分** | 客观计分，按数量/规模 | 材料齐全度决定得分，缺一不可 | 5–15 |
| **资质认证分** | 客观计分 | 有就附，没有不能造 | 3–10 |
| **人员配置分** | 客观+主观混合 | 证书 + 社保 + 简历三件套 | 3–10 |
| **服务承诺分** | 主观，看承诺力度 | 需在成本可控范围内给足 | 3–10 |
| **演示/答辩分** | 现场评分 | 提前排练，控制时长 | 0–10 |

## 三、得分点作战表（核心工具）

每个评分项拆成一行，字段固定：

| 字段 | 填法 | 例 |
|---|---|---|
| `score_id` | S-01 起 | S-03 |
| `score_item` | 评分项名称（照抄） | 类似项目业绩 |
| `score_max` | 满分 | 8 |
| `score_rule` | 计分规则（照抄） | 每提供 1 个同类合同得 2 分，最多 8 分 |
| `evidence` | 需要的证明材料 | 合同关键页 + 验收报告 |
| `our_status` | 现有数量/等级 | 3 个 |
| `expected` | 预期得分 | 6 |
| `gap` | 缺口 | 差 1 个合同 = 2 分 |
| `action` | 补齐动作 | 从关联领域找可认定项目，准备等同性说明 |
| `owner` | 责任人 | 商务部-张 |
| `deadline` | 补齐截止 | 投标前 5 日 |
| `chapter` | 承载章节 | 第 4 章 4.3 |

**用法**：整表按 `gap × score_max` 排序，从上往下做。做完一行划掉一行。

## 四、主观分（技术方案分）的拿分逻辑

主观评分看似玄学，其实有稳定规律。评委通常按"有没有、全不全、专不专业"三层给分：

### 第一层：有没有（保底 60%）
- 招标要求的内容是否**全部出现**
- 是否**按评分表的条目组织**（评委按条目找，找不到就不给分）

> 做法：把评分表的每个子项直接做成三级标题。评委翻到就能打勾。

### 第二层：全不全（中间 25%）
- 每个子项是否有**足够的展开深度**（一般 800–2000 字/子项，视总分而定）
- 是否配了**图**（架构图、拓扑图、流程图、进度甘特图）——纯文字方案在主观分上天然吃亏
- 是否有**量化指标**支撑

### 第三层：专不专业（顶端 15%）
- 是否有**对本项目具体场景的理解**（不是通用模板）
- 是否指出**项目难点并给出针对性措施**
- 是否有**可验证的承诺**而非空话

> **最容易拉开差距的是"对本项目的理解"这一项。**
> 通用模板谁都能写，写出"这个项目的机房在几楼、承重多少、原有系统什么版本、割接窗口只能安排在夜里"才是差异化。
> 这些信息只能来自现场勘察与澄清函——**所以勘察和澄清是用最低成本换最高分的动作。**

## 五、正偏离的使用纪律

"正偏离"指超出招标要求。它可以加分，也可以挖坑。

| 情形 | 建议 |
|---|---|
| 招标要求"≥1000 路"，我方产品 2000 路 | ✅ 写正偏离，说明余量 |
| 招标要求"3 年质保"，主动给 5 年 | ⚠️ 谨慎：写入即成义务，需成本核定 |
| 免费赠送额外模块 | ⚠️ 谨慎：赠送物也需交付与质保 |
| 承诺更短工期 | ⚠️ 高风险：工期违约条款通常很重 |

**纪律**：正偏离只在"产品本身就有、无额外成本"时使用。
凡是需要**额外投入**的正偏离，一律走铁律 5（需决策人批准）。

## 六、评分表与章节的交叉校验（交付前必做）

反向检查一遍：**每个评分项都能在方案里找到对应章节吗？**

```
评分项 S-01..S-nn  →  章节号（必须全部有值）
章节 1..N          →  至少服务一个评分项或有明确的存在理由（招标要求）
```

出现以下情况必须修：

- 某评分项无对应章节 → **直接丢该分**
- 某章节不服务任何评分项、也不对应任何招标要求 → **注水章节，删或压缩**
- 某评分项对应章节篇幅明显不足（如 8 分的项只写 300 字）→ **配比失衡，扩充**

## 七、常见评分陷阱

| 陷阱 | 说明 |
|---|---|
| **分值错觉** | 看到"技术方案 40 分"就全力写方案，忽略了"业绩 15 分"是**客观分、拿满更容易** |
| **小数点竞争** | 技术分差通常只有 2–5 分，而价格分差可能 10 分以上。方案写到 95 分也抵不过报价策略失误 |
| **暗分** | 评分表外的"整体印象分""响应文件规范性"往往隐藏在细则里，格式规范是免费的分 |
| **材料时效** | 业绩合同要求"近三年"，起算点常是投标截止日而非签约日，算错就作废 |
| **盖章遗漏** | 每个要求盖章处漏一个，可能整份被判无效。这是**最高频的致命错误** |
| **副本与正本不一致** | 正副本内容必须完全一致，不一致时以正本为准，但可能被质疑 |
